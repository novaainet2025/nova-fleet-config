# /mp — 메타 프롬프트 (Meta-Prompt)

아래 **원본 요청**을 그대로 실행하지 말고, 먼저 프롬프트 엔지니어링 기법으로 **고품질 메타 프롬프트로 변환**한 뒤 그 변환된 프롬프트를 실행한다.

## 원본 요청
$ARGUMENTS

---

## 처리 절차 (반드시 순서대로)

### 1단계 — 변환 (메타 프롬프트 생성)
원본 요청을 아래 5-블록 골격에 맞춰 명확하고 실행 가능한 프롬프트로 재작성한다. 원본에 없는 정보는 **합리적 기본값으로 추론**하되, 사실을 지어내지 말고 모호한 부분은 명시적으로 표시한다.

- **[컨텍스트]** — 이 작업의 배경·전제·관련 환경(언어/프레임워크/파일 위치 등 추정 가능하면 명시)
- **[목표]** — 달성해야 할 구체적 결과물. 측정 가능하게.
- **[제약]** — 지켜야 할 규칙·범위·하지 말아야 할 것·성능/보안 요건
- **[출력형식]** — 코드/문서/표/단계 등 기대 산출물의 형태
- **[검증기준]** — 완료를 어떻게 증명할지 (테스트·실행·T1 증거). CLAUDE.md 검증 영수증 규칙 준수.

### 2단계 — 변환 결과 표시
변환된 메타 프롬프트를 아래 형식으로 **간결하게** 사용자에게 먼저 보여준다:

```
📝 메타 프롬프트 변환
──────────────────────
[컨텍스트] ...
[목표] ...
[제약] ...
[출력형식] ...
[검증기준] ...
```

### 3단계 — 실행
변환된 메타 프롬프트를 **즉시 실행**한다. 추가 확인을 기다리지 않는다. 단, 원본 요청이 아래에 해당하면 실행 전 사용자에게 확인한다:
- 파괴적/비가역 작업 (삭제·덮어쓰기·force·push·deploy·외부 API 호출)
- 두 가지 이상 해석이 가능해 기본값 선택이 결과를 크게 바꾸는 경우

## 규칙
- 원본 요청이 비어 있으면(`$ARGUMENTS`가 공백) 사용법을 안내하고 종료: `사용법: /mp <변환할 요청>`
- 이 프로젝트의 CLAUDE.md 오케스트레이션 규칙(NCO 위임·검증 영수증·거짓 보고 금지)은 변환 후 실행에도 그대로 적용된다.
- 변환은 원본의 **의도를 확장·명료화**하는 것이지, 새 작업을 발명하는 것이 아니다.
